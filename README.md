# هوشا کلاب

هوشا کلاب یک ژورنال کلاب است. هدفش یادگیری دورهمی و خواندن منظم مقاله است. این ریپو محل نگهداری مقاله‌هایی است که در جلسه‌ها خوانده‌ایم و یادداشت‌ها، اسلایدها و برنامهٔ جلسه‌ها هم در آن جمع می‌شود.

## زمان و مکان

- **زمان:** دوشنبه‌ها، ساعت ۱۲:۰۰ تا ۱۳:۳۰
- **مکان:** اتاق سمینار دانشکدهٔ ریاضی

## روند جلسه‌ها

- **قالب هر جلسه:**
  - ارائهٔ مقاله: حدود ۴۰ دقیقه
  - بحث و پرسش: حدود ۴۰ دقیقه
  - جمع‌بندی و هماهنگی جلسهٔ بعد: ۱۰ دقیقه
- **اعلام مقاله:** ارائه‌دهنده دست‌کم یک هفته قبل مقاله را در گروه تلگرام اعلام می‌کند تا همه فرصت خواندنش را داشته باشند.
- **منتقد (discussant):** در هر جلسه یک نفر از قبل چند سؤال یا نقد آماده می‌کند.

## ساختار ریپو

```
journal-club/
├── README.md          # همین فایل
├── schedule.md        # برنامهٔ جلسه‌ها
├── reading-list.md    # مقاله‌های پیشنهادی
└── papers/
    ├── _template/     # قالب یادداشت هر مقاله
    └── YYYY-MM-DD-short-name/
        ├── notes.md
        └── slides.pdf
```

## اضافه کردن یک مقالهٔ تازه

1. پوشهٔ `papers/_template` را کپی کنید و نامش را به شکل `YYYY-MM-DD-short-name` بگذارید (تاریخ جلسه و نام کوتاه مقاله، مثلاً `2026-11-30-attention`).
2. فایل `notes.md` را پر کنید.
3. اسلاید ارائه را با نام `slides.pdf` در همان پوشه بگذارید.
4. ردیف آن جلسه را در `schedule.md` به‌روز کنید.
